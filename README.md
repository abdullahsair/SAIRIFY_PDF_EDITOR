# AcrobatFlow - Professional PDF Reader & Editor

Adobe Acrobat jaisa modern, clean aur powerful software jisme aap kisi bhi PDF file ko open kar sakte hain, edit kar sakte hain, aur finalize karke download kar sakte hain.

## Key Features

1. **Open Any PDF**: Apne computer se koi bhi PDF file drag-and-drop karein ya `Open PDF` button se open karein.
2. **Text Add & Edit**: Kisi bhi jagah click karke naya text likhein, font style, size, color, bold, aur italic change karein.
3. **Whiteout (Erase Existing Text)**: Purane ya unwanted text ke upar white box draw karke usay saaf karein aur uske upar naya text likh lein!
4. **Digital Signature**: Apna signature mouse/touch se draw karein ya naam type karke cursive signature generate karein aur PDF pe stamp karein.
5. **Markups & Drawing**: Freehand pen tool aur colored highlighters se annotations lagayein.
6. **Shapes & Redaction**: Rectangle, Circle, Line, Arrow draw karein ya sensitive information ko black out (redact) karein.
7. **Official Stamps**: Pre-built stamps jaise `APPROVED`, `CONFIDENTIAL`, `PAID`, `URGENT`, `DRAFT`, `VOID`.
8. **Insert Images**: Images, logos ya custom stamps PDF pe add karein.
9. **Page Management**: Page rotate karein (90° Clockwise) ya unwanted page delete karein. Sidebar me live page thumbnails preview available hain.
10. **Save & Download**: `Download PDF` button dabate hi aapki tamaam edits ke sath authentic PDF file direct download ho jati hai.
11. **100% Offline & Private**: Saari files aapke computer par hi process hoti hain, koi data external server par nahi jata.

## Software Run Kaise Karein?

### Option 1: 1-Click Launch
Folder me mojood [`run.bat`](run.bat) file par double click karein. Yeh software start karke browser me open kar dega.

### Option 2: Terminal / Command Prompt
```bash
npm run dev
```
Aur browser me visit karein: `http://localhost:5173`
